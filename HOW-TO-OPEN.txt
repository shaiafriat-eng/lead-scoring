HOW TO OPEN THE LEAD SCORING GUIDE
==================================

There is NO separate "install" file. You have two options:

OPTION 1 — EASIEST (no Node, no npm)
------------------------------------
1. Go to this folder in Finder:
   Documents/Cursor/src/scoring-system/

2. Double-click:
   OPEN-THIS-FILE.html
   (redirects to the multi-page site)

   Or open the home page directly:
   site/index.html

3. Use the top navigation bar to move between pages
   (Home, How it works, Scoring flow, etc.).

   Full path:
   /Users/shai.afriat/Documents/Cursor/src/scoring-system/site/index.html

   To share: send the whole scoring-system folder, or host via GitHub Pages (see DEPLOY.md).


OPTION 2 — Developer version (needs Node.js)
--------------------------------------------
Only if you have Node/npm installed:

   cd src/scoring-system
   npm install
   npm run dev

Then open: http://localhost:5173

Same pages, React + react-router.


REBUILD STATIC PAGES (after editing content)
--------------------------------------------
   npm run build:site
   npm run sync:pages    # if deploying to GitHub Pages


WHAT'S IN THIS FOLDER
---------------------
OPEN-THIS-FILE.html   ← shortcut → site/index.html
site/                 ← multi-page static site (open index.html)
HOW-TO-OPEN.txt       ← This file
package.json          ← Used only for Option 2
README.md             ← More detail
src/                  ← React source (Option 2)
